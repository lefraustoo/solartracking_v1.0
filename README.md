# Solar Tracking System v1.0

This project is an Arduino-based solar tracker that automatically orients a solar panel towards the sun to maximize power generation. It uses a combination of sensors to determine the sun's position and adjust the panel's orientation accordingly.

## Features

- **Automatic Solar Tracking:** Uses Light Dependent Resistors (LDRs) to detect the position of the sun and control servos to align the solar panel.
- **Power Monitoring:** Measures the voltage, current, and power generated by the solar panel using an INA226 sensor.
- **Orientation Sensing:** Uses an MPU6050 accelerometer and gyroscope to determine the orientation of the solar panel.
- **Real-Time Clock:** Keeps track of the time using a DS3231 RTC module.
- **Data Logging:** Outputs sensor data to the serial monitor for real-time monitoring and debugging.

## Hardware

- Arduino-compatible microcontroller (e.g., Teensy)
- 2 Servos (for horizontal and vertical movement)
- 4 Light Dependent Resistors (LDRs)
- INA226 Power Monitor
- MPU6050 Accelerometer and Gyroscope
- DS3231 Real-Time Clock (RTC)
- ADS1115 ADC
- Solar Panel
- External Potentiometer
- Jumper wires and breadboard

## Software

- [PlatformIO](https://platformio.org/)
- [Arduino Framework](https://www.arduino.cc/)

## Setup

1. **Hardware Setup:** Connect the hardware components as shown in the circuit diagram (diagram not included).
2. **Software Setup:**
   - Install [Visual Studio Code](https://code.visualstudio.com/) and the [PlatformIO IDE extension](https://platformio.org/platformio-ide).
   - Clone this repository to your local machine.
   - Open the repository in Visual Studio Code.
   - PlatformIO will automatically install the required libraries.
3. **Configuration:**
   - The pin connections are defined in `src/ASeguidorSolar.cpp`. Modify these definitions if your hardware setup is different.

## Usage

1. **Build and Upload:**
   - Connect the microcontroller to your computer.
   - Build and upload the firmware using the PlatformIO IDE.
2. **Monitoring:**
   - Open the serial monitor to view the sensor data and system status.
